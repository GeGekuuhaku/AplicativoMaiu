# Aplicativo Maiu

Aplicativo multiplataforma de organização pessoal e bem-estar, desenvolvido com .NET MAUI, C# e XAML.

## Sobre o projeto

O Maiu reúne recursos para apoiar a rotina do usuário em uma única aplicação. A interface utiliza navegação por Shell e organiza funcionalidades de produtividade, meditação e configurações.

## Funcionalidades

- Cadastro e acompanhamento de tarefas e subtarefas
- Área de meditação
- Navegação estruturada com .NET MAUI Shell
- Telas de configurações, contato e informações
- Interface multiplataforma baseada em XAML

## Tecnologias

- .NET MAUI
- C#
- XAML
- .NET

## Estrutura principal

```text
AplicativoMaiu/
├── App.xaml
├── AppShell.xaml
├── MainPage.xaml
├── Tarefas.xaml
├── Meditacao.xaml
├── Configuracoes.xaml
├── Contato.xaml
└── Sobre.xaml
```

## Como executar

1. Instale o .NET SDK compatível com o projeto e o workload do .NET MAUI.
2. Clone este repositório.
3. Abra o arquivo `AplicativoMaiu.sln` no Visual Studio.
4. Restaure as dependências e selecione a plataforma desejada.
5. Compile e execute a aplicação.
